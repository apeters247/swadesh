swadesh playground

sacreBLEU, bit for bit, in your browser

This page runs swadesh, a Rust reimplementation of sacreBLEU 2.6.0, compiled to WebAssembly. The output below is byte-identical to sacrebleu on the command line, and nothing leaves your machine.

This is the standalone swadesh CLI compiled for the browser.
      In Python, pip install swadesh and import swadesh as sacrebleu.

    
Why “swadesh”
Morris Swadesh compared languages by how much of a core word list they share:
      I · you · we · this · that · who · what · not · all · many. BLEU counts shared n-grams the same way.
